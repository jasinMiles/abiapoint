# Abiapoint — Idea One-Pager

**Track:** Frontend Development  
**Stack:** HTML, CSS, JavaScript  
**Target user:** People who need to discover local businesses and services in Abia State, Nigeria.
**Problem:** Local businesses can be difficult to find when information is spread across social networks, informal referrals and separate directories.
**Core flow:** Explore listings → search or filter by category/location → view details → save a favourite or suggest a business.
**Data source:** Fictional local sample data in JavaScript for Week 1; browser localStorage for user-added demo entries and favourites.
**In scope:** Responsive directory; category filters; keyword search; location filtering; listing form validation; favourites; empty state.
**Out of scope:** Authentication, backend, verified ratings, payments, booking, chat, moderation.
