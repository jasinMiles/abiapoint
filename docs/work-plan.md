# Abiapoint — Three-week work plan

## Week 1 — Foundations
- Define the local business discovery idea and target users.
- Build responsive home screen and initial interactions.
- Document the idea, scope, risks and run instructions.

## Week 2 — Components and data (current)
- Refactor repeated card markup into reusable rendering functions.
- Move sample data to `data/businesses.json` and load asynchronously.
- Add loading, empty, error and retry states.
- Document component boundaries and track issues.
- Test search, filters, storage and error handling.

## Week 3 — Quality and delivery
- Improve listing detail interaction and accessibility.
- Add automated or repeatable tests where feasible.
- Verify mobile/desktop layout and keyboard interaction.
- Deploy, capture screenshots, update documentation and submit the final evidence.
